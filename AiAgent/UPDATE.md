# 更新日志 (Changelog)

本项目遵循 [Semantic Versioning](https://semver.org/lang/zh-CN/) 语义化版本规范。

---

## [1.15.0] - 2026-08-25

### ✨ 新增与体验升级
- **多会话管理与缓存架构重构**：
  - 引入全新的多会话管理抽屉，支持创建、切换、重命名及删除历史会话；
  - 升级本地存储结构为 `sca.agent.chat.v2`，按域名实现严格的站点隔离。
- **流式响应与交互打磨**：
  - 深度优化 `CAT.agent.conversation` 流式渲染性能，打字机式平滑输出；
  - 支持会话中实时中断/停止生成。
- **界面与样式防护**：
  - 悬浮球贴边吸附与位置记忆算法优化；
  - 消息气泡 Markdown 渲染升级，完善代码块高亮与一键复制功能；
  - 优化弹窗在各类宿主网页中的 CSS 隔离性，防止样式穿透。

---

## [1.10.0] - 2026-08-20

### 🚀 功能演进
- **模型切换能力**：
  - 接入 `CAT.agent.model` API，支持在聊天窗口顶部动态选择并切换可用模型。
- **消息交互优化**：
  - 增加单条消息一键复制与快速重发功能；
  - 优化移动端与窄屏视口下的响应式展示。

---

## [1.0.0] - 2026-08-15

### 🎉 初始版本发布
- **核心功能落地**：
  - 基于 ScriptCat `CAT.agent` 平台搭建悬浮 AI 对话窗口；
  - 悬浮球拖拽、折叠与展开功能；
  - 支持基于 `Config.show_host` 的白名单配置与 Tampermonkey / ScriptCat 菜单控制；
  - 基础 Markdown 消息解析与本地会话缓存。
