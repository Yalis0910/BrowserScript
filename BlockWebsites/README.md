## 🌟 核心特性

### 1. 🎯 灵活的网址通配符匹配
- **通配符支持**：规则支持全局通配符 `*`，可精确匹配特定子域名、路径或带参数的完整 URL。
- **多行规则配置**：支持配置多条拦截规则，每行一条，直观明了。

### 2. ⏱️ 强大的多精度时间段控制
- **小时级简写**：如 `(12-18)`，自动展开为 `12:00:00` 至 `18:59:59`。
- **分秒级精确控制**：支持 `(HH:MM-HH:MM)` 与 `(HH:MM:SS-HH:MM:SS)` 格式。
- **全天候与分时段共存**：未标注时间段的规则全天生效；标注时间段的规则仅在设定时间内触发拦截。

### 3. ⚡ 极速静默拦截与降级兜底
- **秒级自动关闭**：命中规则且在时间段内时，立即调用 `window.close()` 自动关闭标签页。
- **智能防拦截降级**：针对非脚本打开的标签页（浏览器安全策略阻止 `window.close()`），自动清空页面并展示醒目的友好拦截提示屏，防止注意力分散。

## ⚙️ 脚本配置项 (Script Settings)

在 ScriptCat / 油猴脚本设置面板中可配置以下参数：

| 配置参数名 | 中文标签 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `Config.hosts_list` | 要禁止打开的网站 (多个用换行区分) | 多行文本 (`textarea`) | 见下文示例 | 拦截规则列表。每行一条，支持通配符 `*` 与可选时间段。 |

### 规则语法与示例

```text
# 1. 全天候拦截特定域名及子域
https://*.badsite.com/*

# 2. 小时级限制（12:00:00 到 18:59:59 期间禁止访问）
https://example.com (12-18)

# 3. 分秒级精确限制（12:30:00 到 13:30:00 期间禁止访问）
https://rewards.bing.com/dashboard (12:30:00-13:30:00)

# 4. 复杂 URL 通配符与时段结合
https://*.bing.com/?features=*&form=ML2XES* (09:00-17:00)
```

## ⏱️ 时间段语法规范详解

规则后缀通过括号 `(start-end)` 指定时间区间：

| 格式示例 | 实际拦截时间区间 | 说明 |
| :--- | :--- | :--- |
| `(9-18)` | `09:00:00` ~ `18:59:59` | 结束小时缺省位自动补齐至 `59分59秒` |
| `(09:30-11:30)` | `09:30:00` ~ `11:30:59` | 结束分钟缺省位自动补齐至 `59秒` |
| `(12:00:00-23:59:59)` | `12:00:00` ~ `23:59:59` | 全精度时分秒精确限制 |
| *(未填写括号)* | `00:00:00` ~ `23:59:59` | 全天生效，打开即刻关闭 |

## 📋 脚本权限说明 (UserScript Metadata)

```javascript
// @grant        window.close // 调用浏览器关闭标签页 API
// @grant        GM_getValue  // 读取黑名单与时间段规则
// @grant        GM_setValue  // 保存用户自定义规则
// @match        http*://*/*  // 全局匹配
// @noframes                  // 禁止在 iframe 子框架内重复触发
```
