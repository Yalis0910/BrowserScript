# 更新日志 (Changelog)

本项目遵循 [Semantic Versioning](https://semver.org/lang/zh-CN/) 语义化版本规范。

## [1.1.6] - 2026-08-25

### 🚀 移动端滚动防穿透与触摸手势全方位升级
- **移动端 Touch 触摸滑动拦截机制**：
  - 封装专用的全平台滚动防护工具 `bindScrollLock`，新增移动端 `touchstart` 与 `touchmove` 手势监听与边界检测；
  - 智能计算列表与输入框当前 `scrollTop`、`scrollHeight` 与触摸滑动方向，当触达顶部或底部时精确阻止默认滚动（`e.preventDefault()`），彻底消除移动端滑动弹窗时外层宿主网页跟着联动的现象；
  - 为管理窗口注入 `touch-action: none`，为列表与抽屉配置 `-webkit-overflow-scrolling: touch` 与 `touch-action: pan-y`，保证移动端内部滚动流畅且互不干扰。
- **悬浮球与管理窗口 Touch 触摸拖拽支持**：
  - 重构 `makeDraggable` 支持同时响应鼠标事件与移动端触摸事件（`touchstart` / `touchmove` / `touchend`），手机端长按拖拽悬浮球更跟手顺滑。

## [1.1.5] - 2026-08-25

### ✨ 新增 Tampermonkey / 油猴菜单动态配置修改支持
- **多维度扩展菜单控制**：
  - 针对 Tampermonkey 等不支持脚本配置后台直接修改的扩展环境，全面增强 `GM_registerMenuCommand` 菜单系统，提供 4 个专属快捷配置菜单及精美毛玻璃交互弹窗：
  1. **🛡️ 过滤模式切换**：动态展示当前处于白名单还是黑名单，点击弹窗一键互转切换；
  2. **📝 编辑域名规则列表**：提供支持多行文本编辑的大号弹窗，支持通配符 `*` 并提供「+ 添加当前网站」快捷按钮；
  3. **🔒 本地数据加密设置**：动态展示当前加密状态，点击弹窗一键开启/关闭 AES-GCM 256 位加密存储；
  4. **🔄 恢复后自动刷新设置**：动态展示当前自动刷新策略，点击弹窗一键切换「直接刷新」与「不默认刷新（弹窗确认）」。

## [1.1.4] - 2026-08-25

### ✨ 域名过滤模式升级（黑白名单 + 域名列表）
- **灵活的黑白名单双模式**：
  - UserConfig 新增 `filter_mode` 过滤模式配置，支持 **「白名单模式（默认，仅对列表生效）」** 与 **「黑名单模式（排除列表中网站，其他全生效）」**；
  - 提取解析逻辑支持自动兼容完整的中文展示项与纯英文配置。
- **域名规则配置重构与向下兼容**：
  - 将原配置升级为 `Config.host_list`，每行一条规则，支持通配符 `*`（如 `https://*.example.org*` 或 `*.baidu.com`）；
  - 内置自动读取与平滑兼容历史版本中的 `Config.show_host` 数据。
- **扩展菜单与弹窗自适应联动**：
  - 扩展菜单、未激活拦截弹窗以及主管理弹窗均自动感知当前的黑白名单模式，动态调整「永久开启」与「永久关闭」的文案与行为（白名单模式下加入/移出白名单；黑名单模式下移出/加入黑名单）。

## [1.1.3] - 2026-08-25

### 🚀 核心性能与加解密跨端兼容升级
- **Cookie 批量并发处理性能跃升**：
  - 将 `clearAllData` 与 `restoreSession` 中原本串行阻塞执行的 `GM_cookie.delete` 与 `GM_cookie.set` 重构为 `Promise.all` 批量并发异步处理，恢复与清空数十个 Cookie 时耗时降低近 90%。
  - 过滤无效的 `sameSite: "unspecified"` 写入参数，规避特定浏览器内核的底层报错。
- **解耦 UA 的高兼容加解密体系**：
  - `CryptoEngine` 升级密钥派生材料为稳定版本（`LSM_KEY_V2_SNAPSHOT_${host}`），彻底消除因浏览器版本更新或跨设备/跨浏览器导出导入时的解密失败问题；
  - `decrypt` 流程内置自动回退兼容机制，无缝向下兼容历史版本中已保存的快照数据。
- **全局 Paste 快捷恢复防误触收敛**：
  - 快捷快照识别与拦截条件优化为「仅当管理窗口打开」时响应，避免在普通网页浏览、Swagger 或在线代码/JSON 编辑器中正常粘贴时被脚本误拦截。
- **UI 状态指示栏与动效修复**：
  - 点亮管理窗口顶部「Cookie 模式（全量 / 基础）与本地加密状态」指示栏；
  - 补齐宿主 DOM 关键帧淡入动画 `@keyframes lsmFadeIn`。
- **视口防溢出与全局 Hook 幂等性防护**：
  - 新增 `window.resize` 视口边界动态计算与贴边校准，防止浏览器缩小时悬浮球与管理窗口漂移出可视区域；
  - 为 SPA 路由 `history.pushState` / `replaceState` 代理增加 `__LSM_HISTORY_HOOKED__` 幂等标识，防止重复包装。

## [1.1.1] - 2026-08-24

### 🚀 核心性能与数据健壮性升级
- **PBKDF2 派生密钥内存池 (Key Cache)**：
  - 在 `CryptoEngine` 内部引入域名与 Salt 级密钥缓存池，同一会话内复用 `CryptoKey`，彻底消除重复 100,000 次哈希迭代的 CPU 阻塞，恢复与加解密毫秒级响应。
- **Cookie `SameSite` 属性全量适配**：
  - 在 `restoreSession` 中显式回传 `sameSite` 属性，完美兼容现代浏览器跨站认证 Cookie（`SameSite=None/Lax/Strict`），杜绝第三方单点登录 (SSO) 凭证被浏览器静默丢弃。
- **跨浏览器全域 Cookie 彻底清空与规范化**：
  - 彻底清除带点（`.domain.com`）与不带点（`domain.com`）的多级域名 Cookie，避免跨 Chrome / Edge / Firefox 导入时并存两份同名 Cookie。
- **SPA 单页应用 (Vue/React/Angular) 路由动态感知**：
  - 挂载 `history.pushState`、`history.replaceState` 与 `hashchange` 监听，无刷新路由切换时自动更新来源 URL 与快照命名。
- **快照体积预估与指标计算**：
  - 保存抽屉实时计算快照总字节大小（KB），并在体积过大（>1.5MB）时提供轻度黄色预警与状态反馈。

## [1.1.0] - 2026-08-24

### ✨ 新增与重大体验升级
- **全局 Ctrl+V / Paste 智能快照捕获恢复**：
  - 全局监听键盘 `Ctrl+V`（或粘贴操作），智能识别剪贴板中的单条/批量快照 JSON 数据；
  - 检测到快照特征时自动拦截默认行为，弹出快捷恢复确认提示，点击确认即可一键解密还原并生效。
- **快照实时搜索过滤与视觉打磨**：
  - 工具栏下方集成精细化搜索框，输入框具备聚焦蓝色呼吸光晕、图标联动高亮与一键清空按钮 `✕`；
  - 完美适配手机端/小屏模式，支持按快照名称、保存时间或来源 URL 即时模糊筛选。
- **悬浮球智能贴边吸附与呼吸透明度**：
  - 悬浮球拖拽松开后自动计算最近屏幕边缘并平滑吸附贴边，彻底告别悬停在屏幕中央挡视线；
  - 空闲状态下自动保持 `0.65` 轻度透明度，鼠标悬浮时瞬间恢复 `1.0`，兼顾可用性与无干扰体验。
- **当前生效快照状态标识**：
  - 自动记录当前网站正在生效/最近恢复的快照 ID；
  - 对应卡片高亮展示翠绿 `[✓ 当前生效]` 徽章与微光高亮边框，多账号状态一目了然。
- **剪贴板一键流转与免文件快速恢复**：
  - 卡片操作栏新增「复制」按钮，一键将加密快照数据导出至系统剪贴板；
  - `⋮` 下拉菜单新增「从剪贴板恢复(免文件)」，跨浏览器/跨设备无需下载上传文件，粘贴即可秒级恢复。
- **智能去重导入机制**：
  - 导入备份数据时自动比对快照加密指纹，已存在的重复记录自动跳过并弹出清晰的状态提示。

## [1.0.0] - 2026-08-24

### 🎉 初始版本发布
- **全维度快照捕获与还原**：
  - 优先调用 `GM_cookie` API 获取全量（包含 HttpOnly）Cookie，并支持平滑降级为 `document.cookie`；
  - 支持完整的 `localStorage` 与 `sessionStorage` 键值对捕获与还原。
- **高强度本地加密**：
  - 基于 Web Crypto API 实现硬件级 AES-GCM (256-bit) + PBKDF2 动态加密，内存数据恢复后自动擦除（`wipeMemory`）。
- **无干扰交互架构**：
  - 基于 Shadow DOM 彻底隔离宿主页面 CSS 样式；
  - 悬浮球拖拽与多站点独立记忆位置；
  - 支持白名单机制（`Config.show_host`），默认不干扰未配置站点；
  - 深度集成 Tampermonkey / ScriptCat 扩展菜单命令分发。
- **备份与恢复机制**：
  - 记录来源 URL，恢复时支持智能跳转/刷新回保存页面；
  - 切换不同快照前自动彻底清空旧数据，防止状态残留与串号；
  - 支持批量 JSON 导出/导入、单条记录导出以及跨域名导入时的智能安全确认。
